# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please report vulnerabilities through GitHub's private vulnerability reporting:

1. Go to the [Security tab](https://github.com/redhat-actions/metrics/security) of this repository
2. Click "Report a vulnerability"
3. Fill in the details of the vulnerability

You can expect an initial response within 72 hours. We will work with you to understand the issue and develop a fix before any public disclosure.

## Supported Versions

This is a static website with no server-side components. Security updates are applied to the latest version on the `main` branch.
